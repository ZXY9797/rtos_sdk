# 通信 Link 组件边界

`component/link` 是产品无关的通信服务组件，负责帧编解码、静态路由、分阶段
ACK、重传/重放防护、分端口处理频率、优先级业务队列、异步完成、诊断以及链路抽象。
所有扩展保持现有 Link v1 帧头和位域，不在该组件中引入 Link v2。

## 允许内容

- 依赖 OSAL 和驱动抽象。
- 通过 `Link` 子类接入 UART、CAN、BLE 等物理链路。
- 通过公开 API 让产品层配置路由表和处理回调。
- Parser 与业务 Worker 使用不同的静态任务；handler 不在收包快路径执行。
- 长任务使用有超时的 `CompletionToken`，不得保存 `Frame::data`。

## 禁止内容

- 不包含具体产品应用头文件。
- 不写死产品地址、产品命令或产品启动策略。
- 不实现未经认证的动态地址学习；固定产品拓扑使用确定性最长匹配路由。
