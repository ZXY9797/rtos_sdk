# 算法 Algo 组件边界

`component/algo` 是纯算法组件。

## 允许内容

- 定长向量、矩阵、四元数和空间旋转运算。
- Biquad、Lead-Lag、插值、PID、LESO、NTC 查表和扫频信号。
- 与机构无关的单轴限速、限加速度和限加加速度轨迹原语。
- 只依赖标准 C/C++ 头文件。

## 禁止内容

- 不依赖 OSAL。
- 不包含驱动、DTS、bootloader 或产品应用头文件。
- 不进行日志输出、线程创建或硬件访问。
- 不定义产品主题、任务周期、设备通道或云台状态机。

完整姿态 EKF、非正交运动学、三轴姿态规划和闭环控制器属于功能组件，
只复用这里的计算原语，不进入 `algo` 聚合。
