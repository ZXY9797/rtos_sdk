# 三轴非正交手持云台产品架构

> 状态：产品设计基线
>
> 适用范围：小型三轴非正交手持稳定器
>
> 关键硬件边界：无绝对编码器、无手柄 IMU；每轴使用一对极连续 Hall
> 角度传感器；相电流、母线电压、驱动温度和 MOS 温度均为可选能力。

## 1. 设计边界

### 1.1 基础硬件

产品最小配置只要求：

- 相机端六轴 IMU（陀螺仪和加速度计）；
- IMU 加热器及温度反馈；
- 三轴连续 Hall 角度传感器；
- 三轴电机驱动器和 PWM 输出；
- 可关闭功率级的硬件通路；
- 工厂参数存储区和故障记录区。

本文中的“一对极 Hall”指在完整机械转角内可以连续恢复角度的传感器，
例如两路近似正交的模拟 Hall 信号。它不同于三路数字 Hall 的六扇区换相
传感器。如果实际硬件只能输出离散 Hall 状态，则不能直接实现本文要求的
高分辨率关节位置和低速稳定控制，必须增加角度观测手段或重新定义性能指标。

### 1.2 可选硬件能力

以下采样均不得作为基础配置的必选项：

- 电机相电流；
- 母线电压；
- 驱动芯片温度；
- MOS 温度。

软件必须通过编译期配置和运行期 `CapabilitySet` 描述实际能力。未安装传感器
时，不得发布伪造的默认测量值，也不得宣称具备对应的过流、欠压或过温软件
保护能力。

### 1.3 可观测性边界

系统没有手柄 IMU，也不默认存在磁力计或外部视觉航向源。因此：

- 相机端 IMU 提供相机姿态和角速度；
- 三轴 Hall 提供相机组件相对手柄的关节角；
- 手柄姿态由相机姿态与完整三轴运动学关系反解；
- 世界坐标系绝对 yaw 不可观，长期航向仍会漂移；
- IMU 恒温可以降低零偏温漂，但不能使绝对 yaw 变得可观。

## 2. 总体分层

```text
Product / Mode
  Follow | Lock | FPV | Recenter | Calibration | Diagnostics
                         |
Motion Planning          |  SO(3) reference + smoothed trapezoid
                         v
Control                  |  attitude/rate control + feedforward + decoupling
                         v
Kinematics & Dynamics    |  non-orthogonal FK/Jacobian/inverse dynamics
                         v
Estimation               |  Hall joint state + IMU ESKF + handle estimator
                         v
Motor Control            |  voltage FOC or current FOC
                         v
Device / HAL             |  Hall, IMU, heater, PWM, optional ADC/temperature
```

每层只依赖下层的稳定接口。产品模式不得直接访问 ADC、PWM 或寄存器；算法层
不得依赖具体芯片 SDK。板级差异由设备树描述，功能裁剪由 Kconfig 控制，工厂
差异由参数系统承载。

## 3. Hall 角度与标定

### 3.1 角度模型

对两路连续 Hall 原始信号 `v = [v1, v2]^T`，先消除零偏、增益不一致和
椭圆误差：

```text
u       = A_hall^-1 * (v - b_hall)
theta_h = atan2(u_y, u_x)
theta_m = wrap(s_m * theta_h + delta_m + L_m(theta_h))
theta_e = wrap(p * theta_m + delta_e + L_e(theta_m))
```

其中：

- `b_hall`、`A_hall`：Hall 信号中心和二维校正矩阵；
- `s_m`：机械方向，取 `+1` 或 `-1`；
- `delta_m`：机械零点；
- `p`：电机极对数；
- `delta_e`：电角度零点；
- `L_m`、`L_e`：可选的周期误差查找表。

机械角和电角度必须分别标定。将电角度零点等同于机械零点会引入持续的
`d/q` 轴误差、转矩波动和发热。

### 3.2 工厂标定流程

每轴标定按以下顺序执行，并由独立状态机驱动：

1. **信号标定**：在工装允许范围内缓慢转动关节，拟合两路 Hall 的中心、
   幅值、相位和椭圆校正矩阵，检查饱和、断线和覆盖角度。
2. **方向与极对数验证**：以严格限幅的低占空比转动，校验机械方向、电角度
   方向以及极对数；观测结果不一致时禁止继续。
3. **电角度标定**：使用低电压定向或缓慢扫角求取 `delta_e`，按需要生成
   电角度补偿表。
4. **机械标定**：在定位工装上标定 `delta_m`、软限位、装配中心和非正交
   轴系零位。
5. **往返验证**：正反向重复运动，检查残差、回差、重复精度和相邻采样
   最大跳变。
6. **固化**：写入带版本、长度、设备序列号、CRC 和提交标记的双副本参数。

无相电流采样的硬件在标定时无法进行软件电流限幅，因此必须使用保守电压、
占空比和斜率限制，并依赖功率级自身保护及机械工装。标定超时、关节不运动、
方向异常或 Hall 无效时立即关闭 PWM。

### 3.3 启动检查

启动时至少检查：

- 工厂记录的版本、CRC、设备型号和轴号；
- Hall 原始值范围、归一化向量模长和角度连续性；
- 机械角是否位于允许范围；
- 电角度与机械角映射是否完整；
- 上电静止窗口内的噪声和漂移。

标定记录无效时只能进入服务标定模式，不能使能电机。若实际 Hall 不能在
关节行程内提供唯一的单圈角度，则上电还必须执行可靠的机械回零，不能通过
保存上次关机角度替代回零。

## 4. 电机控制能力分级

### 4.1 无相电流采样：Hall 有感电压 FOC

这是最小硬件的基础模式：

- Hall 机械角经极对数和电角度标定生成转子电角度；
- 外环输出 `v_q`，按需要给定受限的 `v_d`；
- 逆 Park/Clarke 变换后由 SVPWM 输出；
- 使用占空比、`v_q` 斜率、速度和位置范围限制保护小型机构。

该模式不是电流闭环，也不是真实转矩闭环。动力学前馈只能通过电机参数和
标称母线电压近似映射为 `v_q` 或占空比，负载变化、电阻温升和电池电压变化
都会影响实际转矩。

频域辨识时，基础模式的对象定义为：

```text
v_q command (or duty) -> joint angular velocity
```

### 4.2 有相电流采样：电流 FOC

只有能力清单确认相电流采样、偏置标定和采样时序有效时，才允许启用电流
FOC：

- `i_d/i_q` 电流 PI 位于最内环；
- 力矩前馈通过 `tau / K_t` 转换为 `i_q_ref`；
- 速度和姿态环输出力矩或 `i_q_ref`；
- 过流阈值和采样异常进入安全状态机。

此时频域辨识对象定义为：

```text
i_q_ref -> joint angular velocity
```

两种对象不能共用同一组控制器参数或频响验收结果。

### 4.3 其他可选采样

| 能力 | 已安装时 | 未安装时 |
|---|---|---|
| 母线电压 | 电压前馈、欠压/过压检测、功率估算 | 使用工厂标称范围和保守占空比，不宣称欠压/过压软件保护 |
| 驱动温度 | 温度降额和关断 | 依赖驱动器硬件保护与保守持续输出模型 |
| MOS 温度 | 热降额、热模型校正 | 使用时间-占空比热预算，不宣称 MOS 过温检测 |
| 相电流 | 电流环、过流检测、转矩估算 | 使用电压 FOC，只能做堵转间接判断 |

能力缺失时采用“降额或禁止功能”，不能用估算值代替安全传感器的测量值。

### 4.4 构建约束

建议提供以下互斥配置：

```text
CONFIG_GIMBAL_MOTOR_VOLTAGE_FOC=y
CONFIG_GIMBAL_MOTOR_CURRENT_FOC=n
CONFIG_GIMBAL_VBUS_SENSE=n
CONFIG_GIMBAL_DRIVER_TEMP_SENSE=n
CONFIG_GIMBAL_MOS_TEMP_SENSE=n
```

选择电流 FOC 却没有配置电流 ADC 时，CMake/Kconfig 必须在配置阶段失败。
设备树只描述真实存在的通道，驱动创建后再生成只读 `CapabilitySet`，供参数
校验、安全策略和诊断模块使用。

当前实现使用独立的 `rtos_sdk,gimbal-voltage-motor` binding，只描述三相 PWM、
标称母线电压和 SVPWM 调制度，不继承 `foc,motor` 对相电流与母线 ADC 的必选
约束。产品选择电压模式时会选择 `CONFIG_FOC_VOLTAGE_CONTROL`；只有 DTS 提供
`foc,motor` 且同步采样链完成时，Kconfig 才允许选择
`CONFIG_FOC_CURRENT_CONTROL`。可选遥测仍受构建门禁保护。

## 5. 单 IMU 姿态融合与手柄状态估计

### 5.1 坐标系与非正交运动学

定义：

- `W`：惯性/世界坐标系；
- `H`：手柄基座坐标系；
- `C`：相机 IMU 坐标系；
- `q = [q1, q2, q3]^T`：三轴 Hall 机械角。

三轴非正交结构使用乘积指数模型：

```text
T_HC(q) = exp([S1]q1) * exp([S2]q2) * exp([S3]q3) * M
```

`S1..S3` 必须由机构标定得到，不能把三个轴硬编码为相互垂直的 Euler 轴。
相机 EKF 给出 `R_WC` 后，手柄姿态估计为：

```text
R_WH = R_WC * inverse(R_HC(q))
```

因此不能简单使用“相机 yaw 减去 yaw 关节角”。该标量近似会把 roll/pitch
运动和装配非正交误差串入手柄 yaw。

若 `J_omega^H(q)` 将关节速度映射为相机相对手柄角速度，则：

```text
omega_WH^W = omega_WC^W - R_WH * J_omega^H(q) * q_dot
```

这里的 `q_dot` 来自 Hall 角度展开后的带限微分，可用于判断用户对手柄的
yaw 转动意图和生成跟随参考。

非正交结构的闭环输出不能用固定的 roll/pitch/yaw 对电机映射代替。当前关节角
下，相机坐标系控制力矩和相机角加速度分别按以下映射进入关节空间：

```text
tau_joint = J_omega^H(q)^T * R_HC(q) * tau_camera
q_ddot_ref = J_omega^H(q)^-1 * R_HC(q) * alpha_camera
```

第一式满足虚功一致性，第二式为当前控制周期的局部运动逆映射。Jacobian
不可逆、非有限或低于工厂奇异阈值时不得沿用上一周期映射，必须关闭输出。

### 5.2 EKF 基线

使用误差状态 EKF（ESKF）或乘法 EKF：

- 名义状态至少包含姿态四元数 `q_WC` 和陀螺零偏 `b_g`；
- 预测使用经过时间同步和温度补偿的陀螺数据；
- 加速度计仅在模长和动态判据通过时用于重力方向更新；
- 静止判据同时使用陀螺、加速度计和三轴 Hall 速度；
- 静止时更新陀螺零偏并收紧 roll/pitch 协方差；
- 输出应预测到控制执行时刻，避免采样、任务和 PWM 延迟造成相位损失。

没有磁力计、视觉或其他航向观测时，滤波器必须让 yaw 协方差随时间增长，
不能用数值归一化掩盖不可观测性。

### 5.3 yaw 使用策略

- **Lock**：维持短中期惯性航向，但允许并诊断长期漂移；
- **Follow**：主要使用反解后的手柄角速度和转动意图生成 yaw 参考；
- **Recenter**：由用户主动重置当前航向基准；
- **静止校偏**：手柄和全部关节静止时更新陀螺零偏；
- **降级**：EKF 不健康或 Hall 过期时禁止继续使用推算的手柄姿态。

## 6. IMU 恒温控制

### 6.1 启动状态机

```text
Boot
  -> ParameterCheck
  -> HallSelfTest
  -> ImuHeating
  -> TemperatureStable
  -> GyroBiasCalibrate
  -> Standby
  -> Arming
  -> Active
```

在温度和零偏稳定门限通过前，默认不得进入正常增稳。若产品要求快速启动，
只能显式进入受限的 `DegradedWarmup`，同时降低控制带宽、输出能力并上报质量
状态。

### 6.2 加热控制

- 预热阶段采用最大占空比受限的升温控制；
- 恒温阶段采用 10--50 Hz 的 PI/PID；
- 设置目标温度、允许带宽、稳定保持时间、最大占空比、最大温升速率、预热
  超时和硬件允许的最高温度；
- 环境温度高于目标温度时关闭加热器，EKF 继续使用温度补偿；
- 检测“有加热命令但温度不升”和“温度失控上升”；
- 加热 PWM 与 IMU 采样错相，或通过硬件/数字滤波抑制电源纹波耦合。

恒温目标属于工厂参数，由 IMU 规格、环境范围和加热能力验证得到，不向普通
用户开放。加热器故障必须关闭加热 PWM，并根据实测漂移性能决定禁止增稳或
进入降级模式。

恒温只减少温度变化引起的零偏变化。EKF 仍需估计 `b_g`，工厂参数仍需保存
陀螺零偏随温度的补偿曲线作为预热和高环境温度下的兜底。

## 7. 运动学、动力学与闭环控制

### 7.1 动力学模型

完整模型为：

```text
M(q) * q_ddot + C(q, q_dot) * q_dot + G(q)
  + F(q_dot) + tau_cog(q) = tau_motor + tau_ext
```

模型包含非正交耦合、重力、粘性/库仑摩擦、电机齿槽转矩和相机负载参数。
工厂型号参数给出轴系和空载模型，云台调平或负载辨识得到产品运行时负载
修正量。

当前通用组件实现可落地的第一阶段模型：用实时 Jacobian 逆映射得到关节参考
加速度，再叠加对称正定惯量矩阵、单轴重力、粘性/库仑摩擦、齿槽和反电势。
若整机辨识表明 `C(q,q_dot)`、`J_dot*q_dot` 或姿态相关惯量不可忽略，应在保持
相同失效接口的前提下升级为参数调度模型，不能通过提高反馈增益补偿模型缺失。

- 电流 FOC：`tau_ff` 通过 `K_t` 映射为 `i_q_ref`；
- 电压 FOC：使用 `R_s`、`K_e`、`K_t` 和可用的母线电压估算 `v_q_ff`，并
  对前馈幅度进行更严格限幅。

### 7.2 两自由度控制

每个姿态轴采用前馈和反馈分离的两自由度结构：

```text
reference -> planner -> model feedforward ----+
                                              +-> limiter -> motor control
attitude/rate error -> feedback compensator --+
```

反馈设计使用完整 `3 x 3` 频响矩阵检查轴间耦合。在不同姿态、负载和能力
配置下分别辨识；根据模态加入 PI/lead、低通和窄带 notch，不以多个未经验证
的低通滤波器代替频域设计。

建议的首轮设计范围为：

| 环节 | 更新率 | 初始交越频率 |
|---|---:|---:|
| PWM/电流环（可选） | 20--40 kHz | 1--4 kHz |
| 角速度环 | 1--2 kHz | 80--200 Hz |
| 姿态环 | 500 Hz--1 kHz | 10--30 Hz |
| 运动规划 | 100--250 Hz | 不适用 |
| IMU 恒温 | 10--50 Hz | 由热模型确定 |

这些数值是辨识起点，不是验收结论。量产参数应满足至少 45 度相位裕度、
6 dB 增益裕度，并检查 notch、数字延迟、Hall 滤波和共享内存读取造成的额外
相位损失。

## 8. 运动规划与启停手感

轨迹层使用梯形速度规划作为约束骨架，在加速度切换处增加受限 jerk，形成
平滑梯形或七段 S 曲线。姿态轨迹沿 SO(3) 最短旋转插值，避免三个 Euler 轴
分别规划产生绕行和非正交耦合。

建议状态：

```text
Idle -> StartDelay -> SoftStart -> Accel -> Cruise
     -> Decel -> Capture -> Settle -> Hold
```

关键手感参数包括跟随死区、启动延迟、最大速度、加速度、减速度、jerk、
制动提前量、捕获刚度、稳态阻尼和反向迟滞。用户参数只能在工厂安全包络内
调整；关节软限位、奇异区和能力降额可以进一步收紧规划约束。

## 9. 共享内存数据面

模块间使用有类型的共享内存黑板，不共享算法内部对象。每个主题只允许一个
写者，多个读者读取一致快照：

| 主题 | 写者 | 主要读者 |
|---|---|---|
| `ImuBatch[2]` | SPI DMA / `SensorBatchCore` | `g_closed`（const 指针） |
| `ImuState` | `g_closed` | 恒温、安全、诊断 |
| `JointState` | `g_closed` | 电机、运动学、安全 |
| `ImuThermalState` | 恒温任务 | EKF、安全、诊断 |
| `AttitudeState` | EKF | 控制、手柄估计、诊断 |
| `HandleState` | 手柄估计 | 模式与规划 |
| `MotionReference` | 规划器 | 控制器 |
| `MotorCommand` | 控制器 | 电机任务 |
| `MotorFeedback` | 电机任务 | 控制、安全、诊断 |
| `CapabilitySet` | 平台初始化 | 参数、安全、诊断 |
| `SafetyEnvelope` | 安全管理器 | 规划、控制、电机 |
| `ParameterSnapshot` | 参数服务 | 全部算法任务 |

IMU 高频样本使用两个静态批次缓冲区，并由显式所有权状态防止 DMA 覆盖；
缓冲指针不得保存到闭环回调之外。最新状态使用至少三槽的读者计数快照。
每份数据至少包含：

```text
schema_version, sequence, capture_time, publish_time,
valid_flags, health, payload
```

`SensorBatchCore` 允许最多四个异步源共享一个逻辑触发序列，每个 frame 用
`valid_sources` 标出实际完成的源。当前产品只注册 SPI IMU；Hall 尚无 ADC DMA，
所以只在 1 kHz 批次边界软件对齐，不能声称硬件同步采样。

ISR 不加锁、不分配内存、不调用虚函数。读者使用有界重试，超过数据新鲜度
门限后执行该主题规定的降级或关断动作，不能继续消费旧数据。

## 10. 参数系统

参数按职责分层，后层只能在前层允许范围内覆盖：

1. **编译期安全默认值**：确保空白 Flash 也不会产生危险输出；
2. **产品型号参数**：机构、电机、额定电源和默认控制器；
3. **能力清单**：实际安装的传感器和功率级能力；
4. **工厂参数**：单机标定结果；
5. **用户参数**：模式和手感偏好；
6. **运行时参数**：估计零偏、质量状态和降额结果。

### 10.1 工厂参数

- 三轴 Hall 信号矩阵、偏置、方向、机械零点、软限位和误差表；
- 极对数、电角度零点和电角度误差表；
- 非正交螺旋轴 `S1..S3`、坐标外参和装配中心；
- IMU 零偏、3×3 比例/轴不正交/IMU 到相机组合校正矩阵和温度补偿；
- 恒温目标、PI/PID、稳定判据、超时、占空比和最高温度；
- 电机 `R_s/K_e/K_t`、摩擦、齿槽和动力学模型；
- 分能力配置的控制器、notch、滤波器和频响版本；
- 可选电流、电压、驱动温度和 MOS 温度的标定及保护阈值；
- 参数 schema、硬件版本、序列号、生成工具版本和验收摘要。

### 10.2 用户参数

- Lock/Follow/FPV 模式；
- 各轴跟随开关、死区、跟随速度和响应柔和度；
- 允许范围内的速度、加速度、减速度和 jerk；
- 回中、倒置和用户姿态偏置。

用户参数不能覆盖关节硬限制、功率限制、恒温安全阈值或传感器能力。持久化
记录采用 A/B 双副本、单调序号、长度、schema、CRC 和最后写入的提交标记；
升级程序负责版本迁移，迁移失败时回退安全默认值并禁止使能电机。
当前 schema 还由工厂参数限制跟随死区与跟随增益上限；工厂参数更新后旧用户
记录必须重新校验，不能继续沿用旧包络下的手感设置。

## 11. 系统状态与安全策略

顶层状态建议为：

```text
Off -> Boot -> SelfTest -> Heating -> Standby -> Arming -> Active
                  |          |          |          |
                  +----------+----------+---------> Fault

Service: HallCalibration | KinematicCalibration | FrequencyIdentify
```

基础配置必须能够检测并处理：

- Hall 断线、饱和、过期、角度跳变和机械越界；
- IMU 过期、时间戳异常、EKF 发散和姿态质量不足；
- 电机命令过期、控制任务超期、关节超速和奇异区；
- 高输出但 Hall 长时间无运动的间接堵转；
- 加热器过温、升温超时、异常升温和温度采样失效；
- 工厂参数、能力清单或软硬件型号不匹配。

有对应采样时再增加过流、母线欠压/过压、驱动过温和 MOS 过温保护。严重
故障必须将电机命令置零、关闭 PWM/门极使能、锁存首故障及上下文，并由明确
的恢复策略决定是否允许重试。
控制周期失约使用独立故障位锁存；首故障上下文先保存在 RAM，持久化由低优先级
故障日志服务完成，禁止在控制或中断路径直接擦写 Flash。

## 12. 组件目录边界

产品无关能力已经按功能组件落地：

```text
component/
  algo/                # 空间数学、DSP 与单轴限加加速度轨迹原语
  control_contracts/   # 定长领域类型和兼容别名，不含执行逻辑
  motion/              # 非正交运动学、动力学和三轴轨迹规划
  attitude/            # IMU 误差状态 EKF
  control/             # 频率整形与 2DOF 前馈反馈控制
  position_sensor/     # 连续双 Hall、机械零位和电角零位标定
  thermal/             # IMU 恒温控制与升温诊断
  safety/              # 故障检测、锁存和电机授权状态机
  foc/                 # 电压/电流 FOC、统一 SVPWM 和 PWM 电机适配
  ipc/                 # 固定容量快照主题与 SPSC 环形队列

app/product/gimbal/
  board/               # 产品语义设备门面
  config/              # Kconfig 与参考设备树
  include/gimbal/      # 产品参数 schema 与共享主题集合
  services/            # 参数存储、参数校验、传感器批次和任务编排
  doc/                 # 本产品设计、标定和验证文档
```

设备适配仍放在 `embedded/`，产品接线、任务栈、参数 schema 和主题拓扑放在
`app/product/<product>/`。通用空间类型位于 `algo`，跨功能固定布局消息位于
`control_contracts`；算法组件只接收值对象或 HAL 抽象，不包含板级 ADC
通道号、GPIO、RTOS 任务或产品持久化策略。公共头文件暂时保留 `gimbal::`
领域命名空间以维持类型和 ABI 契约，但 `attitude`、`thermal`、`safety` 等组件
不再仅为取得公共类型而链接 `motion`。

当前实现已经完成上述边界迁移：连续双 Hall 使用独立的
`rtos_sdk,gimbal-hall-angle` binding；基础电机使用不强制 ADC 的
`rtos_sdk,gimbal-voltage-motor` binding；电压模式和相电流模式共同复用
`component/foc` 的 SVPWM 内核，并由 `FOC_VOLTAGE_CONTROL`/
`FOC_CURRENT_CONTROL` 分源编译。gimbal 基础固件只链接前者，不会误带入 ADC
电流环、观测器和 SoC 专用电机实现。设备树只承载硬件连接，工厂差异
由带 CRC 和代际号的双记录参数承载。

参考 `board.dts` 中的 ADC 通道和 PWM 定时器只用于编译与集成基线。PWM 引脚、
栅极使能、刹车输入和功率级故障脚必须由实际原理图补齐并评审；未完成该项时
不得把参考固件用于带电整机试验。

## 13. 实施状态与验收阶段

### 已实现的软件基线

- 连续 Hall 信号校正、机械/电角零位圆统计、角度映射和软限位；
- 单 IMU 误差状态 EKF、恒温状态机和手柄状态反解；
- 非正交运动学、动力学前馈、平滑梯形规划和 2DOF 控制；
- 三缓冲快照、IMU DMA ping-pong 批次、数据健康与超时门控；
- 电压 FOC 基线、显式 capability、首故障快照和安全状态机；
- 工厂/用户独立 NVS 日志区及各自 A/B 参数记录；
- 主机单元测试和 `gimbal` 固件构建目标。

### 待具体硬件完成：单轴闭环

- 先在电压 FOC 基础模式完成单轴速度/姿态闭环；
- 对每轴做开环扫频、闭环频响和不同姿态/负载验证；
- 有相电流硬件再增加电流 FOC，不影响基础模式接口。

### 待整机参数辨识：三轴模型与手感

- 标定非正交轴系并用外部测量验证正/逆运动学与 Jacobian；
- 识别耦合、惯量、摩擦、重力和电机参数，替换占位工厂参数；
- 标定 Follow/Lock/FPV、回中速度和启动停止手感。

### 阶段 D：产品验证

- Hall 标定残差、重复性、掉电重启和温漂测试；
- 恒温箱内验证预热时间、恒温波动、yaw 漂移和高温降级；
- 不同相机负载、全姿态和电池范围下的 `3 x 3` 频响；
- 共享内存压力、任务超期、数据陈旧和参数掉电故障注入；
- 机械堵转、Hall/IMU 断线、加热器故障和可选传感器故障注入；
- 量产工装覆盖标定、验收、序列号绑定和追溯记录。

发布门禁应分别记录静态分析、单元测试、仿真/HIL、目标板测试、整机性能和
量产工装结果。仅有编译成功或模型仿真不能作为产品级整机验收证据。
