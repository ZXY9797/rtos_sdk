# MD007 V1 关节驱动

硬件依据为 `HB200_EE_MD007_PCB_V1_260908B.pdf` 第 3–6 页。电机和保护参数来自
`rtos_sdk_robor_arm` 的 `ce6db279`、`projects/kmotor/app/config/k6216`。
SDK 中对应 `MotorVariant::ProfileF`，14 极对、64:1 减速比、3.5 Nm/A 力矩系数。
V1 图纸标注 4 A 额定电流，CST 命令按额定转矩的千分比换算。台架上校验力矩方向及输出比例。

| 信号 | GD32F503CEO6 接线 |
| --- | --- |
| 互补 PWM | U/V/W 高侧 PA8/PA9/PA10，低侧 PB13/PB14/PB15 |
| 三相电流及母线 | IU/IV/IW 接 PA0/PA1/PA2，Vbus 接 PA4。ADC0 时序保持 IW/IV/IU/Vbus/PB0/PB1 |
| 转子和关节位置 | 转子 TMR 为 PB0、PB1，输出端双路模拟 Hall 为 PA5、PA6 |
| NTC | MOS 为 PB10，两路绕组为 PC3、PE15 |
| 抱闸 | PC9 给电源使能，PB11 选择吸合电压。两路低电平为上电静止状态 |
| CAN 与诊断串口 | CAN0 RX/TX 为 PA11/PA12，USART0 TX/RX 为 PB6/PB7 |
| 状态灯 | 绿灯 PB8，高电平点亮 |

12 MHz 晶振经 PLL 产生 192 MHz，CAN0 取 APB2 的 192 MHz。仲裁使用 8×24 tq，
有效 1 Mbit/s，采样点 79.2%。数据阶段使用 2×12 tq，有效 8 Mbit/s，采样点 75%，
启用 BRS 及测量加偏移的发射延时补偿。原装 TPT1042V 的额定速率为 5 Mbit/s，
本配置要求实际已装配额定支持 8 Mbit/s 的收发器。
[GD32F503 数据手册](https://www.gd32mcu.com/data/documents/datasheet/GD32F503xx_Datasheet_Rev0.9RC6.pdf)
[TPT1042V 数据手册](https://static.3peak.com/res/doc/ds/Datasheet_TPT1042-TPT1042V.pdf)

TIMER0 中心对齐、20 kHz，关节 ADC 触发 4 kHz。运动模式下先打开吸合电压，再等待
300 ms 后切换至保持电压，随后才允许 PWM 输出。过温、母线电压异常、采样失效和网络
命令失联走停机链路，关闭 PWM 并拉低两路抱闸输出。释放完成由软件时序判断。

## 构建

App 的板级配置在 `config/app.overlay` 中，由 `md007_v1` profile 选择。

```shell
cmake -S . -B out/md007-v1 -G Ninja -Dp=demo_foc -Dt=armgcc9 -DPROFILE=md007_v1
cmake --build out/md007-v1 --parallel
```

该配置默认用于读数和总线联调。需要启用运动执行时，通过配置片段启用
`CONFIG_DEMO_FOC_MD007_MOTION`。测试矩阵使用 `tests/config/md007_motion.conf`
编译该分支。运动前通过 UART Link 完成传感器标定并写入实际关节限位。MD007 的 NVS
记录键与旧 demo 分离。节点 ID 由 `CONFIG_DEMO_FOC_CANOPEN_NODE_ID` 配置，
范围 1–127，默认 1。整机中的每个轴需使用独立 ID。

三类 Boot 镜像均可用 `-DPROFILE=md007_v1` 配合各自的 `-DFIRMWARE_TYPE`
构建。upgrade 镜像还需传入对应 loader 的 `-DLOADER_PAYLOAD_FILE`。

## CANopen FD 接口

CAN0 专用于 CANopen FD，UART Link 保留校准、诊断和配置。过程数据采用固定映射，
主站可通过快速单播 USDO 读取对象字典和映射表。NMT 启动后由主站每 2 ms 发一次
FD SYNC。软件使用本轮处理中最近一份有效采样，样本年龄超过 1 ms 时跳过发送。
CAN 邮箱忙时丢弃本轮，过期的待发送反馈会请求撤销。
[CiA 1301 协议概要](https://www.can-cia.org/can-knowledge/canopen-fd-the-art-of-embedded-networking)
[CiA 402 驱动与运动控制](https://www.can-cia.org/can-knowledge/cia-402-series-canopen-device-profile-for-drives-and-motion-control)

| COB-ID | 方向 | 功能 |
| --- | --- | --- |
| `000h` | RX | NMT Start、Stop、Pre-operational、Reset Communication |
| `080h` | RX | 2 ms SYNC，载荷为空或包含 1–240 的单字节计数 |
| `180h + ID` | TX | 32 字节 TPDO1，每个有效 SYNC 最多一帧 |
| `200h + ID` | RX | 16 字节 RPDO1，运动配置启用后，在下一次 SYNC 应用 |
| `600h + 客户端 ID` | RX | 单播快速 USDO 上传请求，目的节点位于数据字段 |
| `580h + ID` | TX | USDO 上传应答或中止应答 |
| `700h + ID` | TX | Boot-up 和 100 ms 心跳 |

TPDO1 采用小端序，映射可从 `1A00h` 读取。

| 字节 | 对象 | 单位或含义 |
| --- | --- | --- |
| 0–1 | `6041h` | Statusword |
| 2–5 | `6064h` | 关节位置，µrad，有符号 |
| 6–9 | `606Ch` | 关节速度，µrad/s，有符号 |
| 10–13 | `2000h:01` | q 轴反馈电流，mA |
| 14–17 | `2000h:02` | 母线电压，mV |
| 18–21 | `2000h:03` | 本节点采样时标，µs，32 位循环计数 |
| 22–25 | `2000h:04` | 关节采样序号 |
| 26–29 | `2000h:05` | 本地保护标志 |
| 30 | `2000h:06` | SYNC 计数，无计数时为 0 |
| 31 | `6061h` | 生效的 CSP 8、CSV 9、CST 10，未接管运动时为 0 |

RPDO1 按 `6040h` Controlword、`6060h` Mode、`607Ah` 位置 µrad、
`60FFh` 速度 µrad/s、`6071h` 额定转矩千分比排列，小端序，尾部补 3 个零。
经 Shutdown、Switch on、Enable operation 顺序进入运动。CSP、CSV、CST 之间
切换先退出使能。6 ms 内无新 RPDO 经 SYNC 应用会进入 fault，恢复需显式复位并重新使能。

当前接口覆盖上述固定 PDO 和快速读对象。完整 CiA 1301/402-6 一致性验证、可写和分段
USDO、EMCY、LSS 仍属于后续联调范围。8 Mbit/s 波形、同步上报抖动、负载下抱闸和
限位停车需要在换装收发器后使用目标板验证。
