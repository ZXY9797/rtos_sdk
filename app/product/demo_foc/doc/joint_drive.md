# FOC 关节驱动示例

`demo_foc` 使用示例板级配置。电机参数为 `MotorVariant::ProfileF`，
14 极对、64:1 减速比、3.5 Nm/A 力矩系数和 4 A 额定电流。
CST 命令按额定转矩的千分比换算。

## 板级配置

| 信号 | GD32F503CEO6 接线 |
| --- | --- |
| 互补 PWM | U/V/W 高侧 PA8/PA9/PA10，低侧 PB13/PB14/PB15 |
| 三相电流及母线 | IU/IV/IW 接 PA0/PA1/PA2，Vbus 接 PA4。ADC0 时序保持 IW/IV/IU/Vbus/PB0/PB1 |
| 转子和关节位置 | 转子 TMR 为 PB0、PB1，输出端双路模拟 Hall 为 PA5、PA6 |
| NTC | MOS 为 PB10，两路绕组为 PC3、PE15 |
| 抱闸 | PC9 给电源使能，PB11 选择吸合电压。两路低电平为上电静止状态 |
| CAN 与诊断串口 | CAN0 RX/TX 为 PA11/PA12，USART0 TX/RX 为 PB6/PB7 |
| 状态灯 | 绿灯 PB8，高电平点亮 |

App 和 Boot 共用 `config/board_defconfig` 中的 12 MHz 晶振与 192 MHz PLL 配置。
CAN0 取 APB2 的 192 MHz。仲裁使用 8×24 tq，
有效 1 Mbit/s，采样点 79.2%。数据阶段使用 2×12 tq，有效 8 Mbit/s，采样点 75%，
启用 BRS 及发射延时补偿，`tdc-offset` 为 18。收发器须支持 8 Mbit/s 数据段。

TIMER0 中心对齐、20 kHz，关节 ADC 触发 4 kHz。节点先在抱闸闭合时建立保持电流，
位置、速度和电流满足配置的稳定时间后才松闸，释放延时结束后执行主站目标。
正常停机与通信超时在本地减速并保持，待速度和保持电流稳定后合闸，继续供电至合闸延时结束。
电流、反馈和电源严重故障走快速关断。抱闸状态来自驱动时序，本板没有闸位反馈。

## 构建

App 的外设、时序和通道配置位于 `config/app.overlay`。

```shell
cmake -S . -B out/demo_foc -G Ninja -Dp=demo_foc -Dt=armgcc9
cmake --build out/demo_foc --parallel
```

该配置默认用于读数和总线联调。需要启用运动执行时，通过配置片段启用
`CONFIG_DEMO_FOC_JOINT_MOTION`。测试矩阵使用 `tests/config/demo_foc_motion.conf`
编译运动路径。机械支撑负载后，使用 UART 工具 `supported-service 1` 进入标定维护，
完成传感器和机械零位标定后用 `supported-service 0` 退出。配置 `limits` 的机械行程、
连续电流与速度限制，配置 `brake` 的带符号保持电流、允许电流误差、预载稳定时间、
松闸和合闸时间、允许位置偏差、静止速度、减速度及保持环增益。时间单位为 ms，
位置为 rad，速度为 rad/s，增益为 A/rad 和 A·s/rad。接触阈值 Nm 与持续时间 ms 可选，
阈值为零关闭接触停机。各轴参数独立，缺失必需参数时禁止正常运动。

每次启动、变更标定或配置、暂停采样后，在静止状态发送 `confirm-axis <机构实测位置rad> <已核对方向±1>`。
节点同时核对零位有效性、方向、行程和单圈角，可从实测机械位置恢复整圈数。示例的
配置方向为 +1。断电移动后的多圈位置需由独立基准提供。启用双端角度外力估算时，还需要在已确认零负载的工况下给 `confirm-axis` 加 `--unloaded`，以对齐转子折算角与输出轴角的弹性零位。缺少这个基准时，导纳和拖动需使用有时效的外部力矩测量。
标定记录从 NVS 的 `0x4200` 起编号，交互控制配置使用 `0x4300`。
节点 ID 由 `CONFIG_DEMO_FOC_CANOPEN_NODE_ID` 配置，
范围 1–127，默认 1。整机中的每个轴需使用独立 ID。

Boot 镜像用 `-DFIRMWARE_TYPE=preloader`、`loader` 或 `upgrade` 选择，
各自的项目配置位于 `boot/<image>/config/`。
构建 upgrade 时传入对应 loader 的 `-DLOADER_PAYLOAD_FILE`。

## CANopen FD 接口

CAN0 专用于 CANopen FD，UART Link 保留校准、诊断和配置。过程数据采用固定映射，
主站可通过快速单播 USDO 读取对象字典和映射表。NMT 启动后由主站每 2 ms 发一次
FD SYNC。软件使用本轮处理中最近一份有效采样，样本年龄超过 1 ms 时跳过发送。
CAN 邮箱忙时丢弃本轮，过期的待发送反馈会请求撤销。

| COB-ID | 方向 | 功能 |
| --- | --- | --- |
| `000h` | RX | NMT Start、Stop、Pre-operational、Reset Communication |
| `080h` | RX | 2 ms SYNC，载荷为空或包含 1–240 的单字节计数 |
| `180h + ID` | TX | 32 字节 TPDO1，每个有效 SYNC 最多一帧 |
| `200h + ID` | RX | 16 字节 RPDO1，运动配置启用后，在下一次 SYNC 应用 |
| `600h + 客户端 ID` | RX | 单播快速 USDO 上传请求，目的节点位于数据字段 |
| `580h + ID` | TX | USDO 上传应答或中止应答 |
| `700h + ID` | TX | Boot-up 和 100 ms 心跳 |

TPDO1 采用小端序，映射可从 `1A00h` 读取。

| 字节 | 对象 | 单位或含义 |
| --- | --- | --- |
| 0–1 | `6041h` | Statusword |
| 2–5 | `6064h` | 关节位置，µrad，有符号 |
| 6–9 | `606Ch` | 关节速度，µrad/s，有符号 |
| 10–13 | `2000h:01` | q 轴反馈电流，mA |
| 14–17 | `2000h:02` | 母线电压，mV |
| 18–21 | `2000h:03` | 本节点采样时标，µs，32 位循环计数 |
| 22–25 | `2000h:04` | 关节采样序号 |
| 26–29 | `2000h:05` | 本地保护标志 |
| 30 | `2000h:06` | SYNC 计数，无计数时为 0 |
| 31 | `6061h` | 生效的 CSP 8、CSV 9、CST 10，未接管运动时为 0 |

RPDO1 按 `6040h` Controlword、`6060h` Mode、`607Ah` 位置 µrad、
`60FFh` 速度 µrad/s、`6071h` 额定转矩千分比排列，小端序，尾部补 3 个零。
经 Shutdown、Switch on、Enable operation 顺序进入运动。CSP、CSV、CST 之间
切换先退出使能。6 ms 内无新 RPDO 经 SYNC 应用会进入受控停机并锁存故障，恢复需显式复位并重新使能。

## 单轴交互和周期确认

扩展 RPDO 使用 `300h + ID`，长度 48 B，小端序。主站先按 6、7、15 的控制字顺序使能，
每帧指定下一次 SYNC 计数 1–240。使用扩展命令后，本次通信会话固定使用扩展格式。
NMT Reset Communication 可重新选择格式。位置、速度、转矩分别沿用模式 8、9、10。
厂商模式 -1 为关节阻抗，-2 为单轴导纳，-3 为拖动。力矩标定有效后才允许物理单位模式。
导纳与拖动还需要已标定的弹性模型或有效外力矩。整臂重力前馈由主站计算。

| 偏移 | 类型 | 字段 |
| --- | --- | --- |
| 0、2、3 | u16、i8、u8 | 控制字、模式、预期 SYNC 计数 |
| 4、8 | u32、u32 | 命令序号、上游输入样本序号，按模 2³² 递增 |
| 12、16 | i32、i32 | 位置 µrad、速度 µrad/s |
| 20 | i32 | 物理模式力矩 mNm，CST 为额定转矩千分比 |
| 24、28 | u32、u32 | 阻抗刚度 mNm/rad、阻尼 mNm·s/rad |
| 32、36 | i32、u32 | 外力矩 mNm、外力样本序号 |
| 40、42 | u16、u16 | 上游输入和外力样本发送时年龄 ms |
| 44、45、46 | u8、u8、i16 | 位 0 表示外力有效，位 1 表示本帧提供保持电流，保留字节填 0，带符号保持电流 mA |

对象 `1401h/1601h`、`1801h/1A01h` 和 `1802h/1A02h` 分别描述命令、周期确认与异步故障事件。厂家记录 `2110h`、`2111h`、`2112h` 的子索引按下发与反馈字段的线序排列。`interaction_tool.py encode-rpdo <JSON文件>` 可生成节点命令的十六进制载荷，`decode-tpdo2 <十六进制载荷>` 可解析周期确认。

同一上游样本可跨多个 2 ms 周期复用，最长 50 ms。主站应保留原始输入序号和年龄。
相同外力序号不会刷新外力超时。每轴 4 kHz 回调独立监督 6 ms 命令超时。
可选接触停机使用有效外力矩或已启用交互模型的估算残差；阈值和持续时间按轴和负载标定。

扩展反馈 `280h + ID` 每个有效 SYNC 尝试发送一次，长度 48 B。

| 偏移 | 类型 | 字段 |
| --- | --- | --- |
| 0、4、8 | 3 × u32 | 最近一次由关节环消费的命令序号、消费时节点 µs、从软件处理 SYNC 至关节环消费的 µs |
| 12、16、20、24 | 4 × u32 | 丢弃计数、过期或不可用反馈计数、遗漏的编号 SYNC 数、最大样本年龄 µs |
| 28–31 | 4 × u8 | 抱闸阶段、力矩有效与来源位、已消费命令有效位、当前 SYNC 计数 |
| 32、36、40、44 | i32、i32、u32、u32 | 根据 Iq 标定估算的输出力矩 mNm、外力矩 mNm、外力样本年龄 µs、首故障掩码 |

抱闸阶段 0–5 依次为锁定、预载、释放中、运行、减速、合闸中。力矩来源位 0 为电流标定估算，
位 1 为外部输入，位 2 为传动模型估算。原始 Iq 保留在 TPDO1。节点时钟相互独立，
比较多轴相位时以同一 SYNC 为基准，用总线分析仪记录实际帧时刻。

故障事件 `380h + ID` 长 12 B，含首故障 u32、节点检测时刻 µs u32、检测时抱闸阶段 u8 和 3 字节保留。
该事件独立于关节样本有效性及 SYNC，邮箱忙会在下一次服务时重试。对象 `2100h`、`2101h`、`2102h`
的子索引 0 可分别查询上述三个字段。位 27–31 依次表示目标被拒、接触停机、上游样本超时、
本地禁止和周期命令超时。通信复位保留首故障，排除故障后以控制字的 Fault Reset 上升沿清除。
